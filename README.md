# Tourism Destination Recommendation

Machine-learning notebooks for exploring and predicting travel destinations from destination attributes.

## Project contents

- `Cleaning.ipynb` prepares the source data, including versions with and without outliers.
- `data_with_Outliers/` contains the model notebooks using outlier-inclusive data.
- `data_withOut_Outliers/` contains the model notebooks with outliers removed.
- `Dataset.csv` is the original destination dataset.

The model notebooks compare decision tree, k-nearest neighbors, logistic regression, and random forest classifiers. They predict a destination country from the remaining encoded destination features.

## Generated data

The one-hot encoded CSV files are generated by `Cleaning.ipynb` and are excluded from this repository because each exceeds GitHub's 100 MB file limit. Run the notebook cells to generate them in their respective data folders before running a model notebook.

## Data source

The cleaning notebooks load the WanderPlan dataset from [Hugging Face](https://huggingface.co/datasets/nirm2002/wanderplan-dataset). `Dataset.csv` is also included as a source data copy.

## Requirements

Python 3 with `pandas`, `numpy`, and `scikit-learn`, plus Jupyter Notebook or JupyterLab.

## Running the notebooks

Run both cells in `Cleaning.ipynb` to generate the preprocessed CSV files, then run the model notebooks from the matching folder.
